# levi-unlock

A small Wii homebrew application that removes the parental control PIN from [uLoader](https://github.com/spacemanspiff/uLoader).</br>
It is meant for recovering a console whose PIN was forgotten.

USE THIS SOFTWARE ONLY ON HARDWARE YOU OWN OR HAVE EXPLICIT PERMISSION TO MODIFY.

## Build

Requirements: devkitPro with devkitPPC and libogc.

```sh
export DEVKITPRO=/opt/devkitpro
export DEVKITPPC=$DEVKITPRO/devkitPPC
make
```
